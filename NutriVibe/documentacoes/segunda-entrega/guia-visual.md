# Guia visual - NutriVibe

Guia para criar telas, componentes e variações visuais do projeto NutriVibe.

## Paleta oficial

| Função | Hex | Uso |
|---|---:|---|
| Verde principal | `#4CAF50` | Botões principais, marca, ações positivas |
| Verde escuro | `#2E7D32` | Títulos, hover, áreas de maior confiança |
| Verde claro | `#E8F5E9` | Fundos suaves, destaques e cards |
| Laranja | `#FF9800` | Gamificação, desafios e alimentos |
| Amarelo | `#FFD54F` | Pontos, conquistas e recompensas |
| Azul | `#42A5F5` | Educação alimentar e conteúdos informativos |
| Vermelho suave | `#EF5350` | Alertas, erros e avisos importantes |
| Fundo | `#F8FAF7` | Fundo geral da interface |
| Card | `#FFFFFF` | Cartões, formulários e painéis |
| Texto principal | `#263238` | Títulos e textos principais |
| Texto secundário | `#607D8B` | Legendas e textos auxiliares |
